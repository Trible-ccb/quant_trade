## 🎯 策略核心逻辑

### 选股流程
```
昨日涨停股 
  ↓ 过滤连板
非连板涨停股
  ↓ 过滤 ST/停牌/科创板/新股
基础合格股
  ↓ 过滤开盘价涨跌幅（-4%~-1%）
开盘价合格股
  ↓ 计算近60日相对低位
  ↓ 按相对位置排序
  ↓ 取 Top10
最终候选股
```

### 交易流程
```
T日 09:28     集合竞价开盘价 → 等权重满仓买入
  ↓
T+1日 11:28   检查浮动盈利 → 有利就卖出
  ↓
T+1日 14:50   无论盈利否 → 全部清仓
```

## ⚙️ 关键参数调整

### 参数 1：开盘价涨跌幅范围
```python
g.open_price_drop_low = -0.04    # 下限，调小≈更严格，调大≈更宽松
g.open_price_drop_high = -0.01    # 上限，调大≈包含更多高开龙头
```

**调整建议**：
- 想要更多交易机会 → 增大上下限范围
- 想要更高质量选股 → 缩小范围

### 参数 2：相对低位阈值
```python
g.relative_low_threshold = 0.30  # 0.30 = 30%以内视为低位
```

**调整建议**：
- 增大 → 选股范围更广（如 0.4）
- 减小 → 严格要求接近底部（如 0.2）

### 参数 3：选股数量
```python
g.top_stock_count = 10           # 选择 Top10 股票
```

**调整建议**：
- 增大 → 每日交易笔数多，分散风险
- 减小 → 集中在最好的标的，收益可能更高但波动大

## 📞 常见问题

**Q: 策略为什么选择非连板涨停？**
A: 连板股已上涨多日，风险累积；单日涨停后回落的股票是次日反弹的优选标的。

**Q: 如何应对无涨停股票的市场？**
A: 策略会返回空持仓。可考虑改为弱势龙头选股（如昨日涨3-5%的股票）。

**Q: 可以改成多日持仓吗？**
A: 可以，但需重新设计卖出逻辑和风险管理。建议先测试当前版本。

**Q: 策略在熊市中表现如何？**
A: 熊市涨停股数量少，交易机会少，收益可能不理想。建议与其他策略组合。
