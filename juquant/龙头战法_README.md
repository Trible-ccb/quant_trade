# 龙头战法策略（JuQuant版）

## 策略简述

龙头战法是一个高频短线策略，利用**昨日涨停股在次日开盘回落**的特性，选择相对低位的龙头股进行T+1日交易。

---

## 策略逻辑

### 选股流程（T日）

1. **获取昨日涨停股**
   - 筛选昨日收盘价 = 涨停价的股票

2. **非连板过滤**
   - 排除近两日都涨停的股票（连板）
   - 只选择单日涨停的龙头

3. **基础过滤**
   - 排除 ST 股、停牌股、科创板（688）
   - 排除上市不足 1 年的新股

4. **开盘价过滤**
   - 今日开盘价涨跌幅：**-4% ~ -1%**（参数可调）
   - 涨停后低开的股票往往具有买入机会

5. **相对位置筛选**
   - 计算近 60 日相对位置：`(当前价 - 最低价) / (最高价 - 最低价)`
   - 选择相对位置 ≤ 50% 的股票（接近底部）
   - 按相对位置从小到大排序，取 **Top 10**

### 交易流程

| 时间 | 操作 | 说明 |
|------|------|------|
| T日 09:28 | **集合竞价买入** | 等权重满仓买入 Top10 股票 |
| T+1日 11:28 | **盈利检查** | 若浮动盈利 > 0，卖出; 否则继续持仓 |
| T+1日 14:50 | **尾盘清仓** | 无论盈利与否，全部卖出 |

---

## 参数配置

```python
# 开盘价涨跌幅范围
g.open_price_drop_low = -0.04   # 下限 -4%
g.open_price_drop_high = -0.01   # 上限 -1%

# 相对低位阈值
g.relative_low_threshold = 0.5  # 30% 以内视为低位

# 选股数量
g.top_stock_count = 10          # 取 Top 10
```

### 参数调整建议

| 参数 | 调整方向 | 说明 |
|------|--------|------|
| `open_price_drop_high` | 增大 | 增加选股范围（如 0.06 = 6%跌幅） |
| `open_price_drop_low` | 减小 | 排除大幅低开的股票（如 -0.03） |
| `relative_low_threshold` | 增大 | 选择范围更广的低位股（如 0.5） |
| `top_stock_count` | 增加 | 持仓更多个股，分散风险 |

---

## 风险管理

1. **每日清仓**
   - T+1日 14:50 必然清空所有持仓，避免隔日风险

2. **止损机制**
   - 依赖于相对低位筛选，具有一定底部保护

3. **头寸管理**
   - 等权重分散到 Top10 股票，避免单只股票风险过高

## 适用场景

✅ **适合**
- 市场高景气时期（涨停数量多）
- 板块轮动明显的市场环境
- 流动性充足的大盘股

❌ **不适合**
- 熊市或弱势市场
- 涨停股数量过少的时期
- 流动性严重不足时期

## 常见问题

### Q: 为什么选择非连板涨停？
A: 连板股已经上涨多日，风险累积较大；单日涨停后回落的股票是次日反弹的优选标的。

### Q: 如何调整风险偏好？
A: 
- **激进**：增加 `top_stock_count` 到 15，降低 `relative_low_threshold` 到 0.2
- **保守**：减少 `top_stock_count` 到 5，提高 `relative_low_threshold` 到 0.4

### Q: 策略为什么在 14:50 必然卖出？
A: 防止隔日持仓风险，保证每日独立交易，避免风险累积。

### Q: 可以改成 T+2 吗？
A: 可以，但需要修改卖出逻辑，添加 T+2日的时间判断，建议先测试当前版本。
